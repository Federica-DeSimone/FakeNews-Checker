# FakeNews-Checker
FakeNews-Checker è una piattaforma web per contrastare la disinformazione online.


📰 Descrizione del Progetto
FakeNews Checker è una piattaforma web progettata per contrastare la disinformazione online, permettendo agli utenti di consultare notizie verificate e segnalare articoli sospetti.
Il sistema mira a promuovere la consapevolezza digitale e il pensiero critico, fornendo uno strumento accessibile e trasparente per la verifica delle notizie.

👥 Utenti e ruoli:
-	Utente non registrato: può solo consultare le notizie
-	Utente registrato: può segnalare articoli attraverso un form inserendo titolo e descrizione e può gestire il proprio profilo
-	Gestore delle verifiche: verifica le segnalazioni (“In Verifica” “Non Attendibile” “Verificata”) nel caso di non attendibile le rimuove dalla homepage. 
-	Gestore Tecnico: si occupa del monitoraggio e della manutenzione della piattaforma. 

⚙️Funzionalità principali: 
✔️consultazione notizie: visibile a tutti gli utenti
🚨 Segnalazione notizie sospette: gli utenti registrati possono segnalare le notizie che ritengono sospette. 
🔍 verifica delle notizie: i gestori controllano le segnalazioni usufruendo di fonti attendibili 
⚙️Monitoraggio tecnico: dashboard per il controllo del sistema, aggiornamenti. 

🖥️ Tecnologie e Ambiente 
Tipo: Piattaforma Web
Browser: Chrome, Opera, Edge, Safari
Tecnologie: HTML, CSS, JavaScript, DB relazionale
